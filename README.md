# Experiment 5 - Node.js & Express.js (Urine Strip Reader use case)

- `1_http_basic_server.js` - http module routing + callback
- `2_file_sync.js`, `3_file_async.js` - sync vs async file operations
- `customModules/analyteMath.js`, `4_custom_module_demo.js` - custom module
- `index.js` - basic Express routing; `expressApp/` - Express + EJS + static middleware
- `index.html`, `patients/`, `api/` - static pre-rendered build of the Express app for GitHub Pages (`node build-static.js` regenerates it)

Run locally: `npm install` then `npm start` (http://localhost:3001).
